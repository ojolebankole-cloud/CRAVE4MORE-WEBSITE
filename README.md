# CRAVE4MORE

Premium 3D restaurant website experience.

**Developer:** Koledev

## Asset Library

- `public/assets/models/` — 3D GLB models.
- `public/assets/images/` — Transparent food images.
- `public/assets/textures/` — 3D model textures.
- `docs/asset-inventory/` — Asset documentation.

## Technology Direction

- React and TypeScript
- Three.js and React Three Fiber
- GSAP and ScrollTrigger
- Motion for React
- Lenis
- Custom shaders and physics where appropriate
